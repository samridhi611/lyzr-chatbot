# Loan Policy Chatbot POC

## Setup
1. `npm install`
2. Create `.env.local` with `LYZR_API_KEY` and `NEXT_PUBLIC_AGENT_ID`
3. `npm run dev`
4. Open `http://localhost:3000` and ask your chatbot questions about your loan policy.

## Notes
- This is a simple POC.
- You can extend by adding file upload, advanced UI, better error handling.
- Ensure your agent in Lyzr has the correct knowledge base linked.
